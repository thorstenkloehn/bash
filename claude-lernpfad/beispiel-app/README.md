# Beispiel-Anwendung: `todo.sh`

Kleine Todo-Verwaltung in Bash. Sie ist der gemeinsame Übungsplatz des Kurses: Du lässt sie mit Claude Code erweitern, schützt sie mit Hooks und prüfst sie automatisch.

```bash
./todo.sh add "Milch kaufen"
./todo.sh list
./todo.sh done 1
./tests/test.sh      # Tests
```

Mögliche Erweiterungen im Kurs: `remove`, Prioritäten, `--help` verbessern, Tests mit `bats`.
